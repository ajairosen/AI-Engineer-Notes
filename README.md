# AI Engineer Interview Prep

Q&A bank built up interactively, one question at a time, organized by category.

## Categories
- Python — split by complexity: [basic.md](python/basic.md), [intermediate.md](python/intermediate.md), [advanced.md](python/advanced.md), plus [theory.md](python/theory.md) for theoretical/situational (non-coding) questions, and [libraries/](python/libraries/) for topic-wise library FAQs ([pandas.md](python/libraries/pandas.md), [numpy.md](python/libraries/numpy.md))
- [rag/questions.md](rag/questions.md) — Retrieval-Augmented Generation
- [agents-langgraph/questions.md](agents-langgraph/questions.md) — Agents & LangGraph
- [production/questions.md](production/questions.md) — Production concerns (agent failure, hallucination, monitoring, etc.)
- [system-design/questions.md](system-design/questions.md) — System design basics for AI systems
- [fine-tuning/questions.md](fine-tuning/questions.md) — LoRA/PEFT and other fine-tuning technique questions
- [llm-fundamentals/questions.md](llm-fundamentals/questions.md) — Core transformer/LLM architecture concepts

## Workflow
- Questions are presented one at a time, shuffled across categories.
- Say **"next"** → the current question (with answer) gets appended to the right category file (Python questions go into `python/basic.md`, `intermediate.md`, or `advanced.md` depending on difficulty), then the next question is presented.
- Say **"ignore"** → the current question is skipped (not saved), next question is presented.
- Say **"CONDUCT TEST"** → pulls existing saved questions from the files and quizzes you on them one by one (answer only, no peeking at the saved answer until you respond).
